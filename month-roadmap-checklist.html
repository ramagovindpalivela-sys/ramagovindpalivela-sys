📅 Week 1: Foundation + Setup ▼
Pick your primary language
Choose: Java, Python, or C++. Java recommended for placements.
Learn language basics
Variables, loops, functions, arrays, strings, conditions
Solve 8-10 easy DSA problems
Use LeetCode or HackerRank. Focus on understanding.
Set up GitHub account
Create account, set profile picture, write bio
Learn Git & GitHub basics
git init, git add, git commit, git push
Choose your first project
To-Do App (recommended), Calculator, or Notes App
Create GitHub profile README
Add your name, bio, skills, and goals
Post progress on Instagram/LinkedIn
Share what you learned today. Build in public.

Learn Arrays & Strings DSA
Understand arrays, indexing, string manipulation
Learn Hashing basics
Hash maps, hash sets, key-value pairs
Learn Two Pointers technique
Solve 3-4 two pointer problems
Solve 12-18 easy/medium DSA problems
Focus on understanding logic, not speed
Start building your project
Set up project structure (HTML/CSS/JS or language of choice)
Implement basic features
Add task, delete task, mark complete, save in localStorage
Create project GitHub repo
Upload code, write README with description
Daily progress posts
Post learning & coding progress on social media
📅 Week 3: Strengthen DSA + Finish Project ▼
Master Recursion basics
Understand recursive calls, base cases, examples
Learn Sorting algorithms
Bubble sort, merge sort, quick sort concepts
Learn Searching algorithms
Binary search, linear search patterns
Solve 15-20 more DSA problems
Try to solve 80% on your own. Aim for consistency.
Improve project UI/UX
Add colors, themes, dark mode, better design
Add advanced features to project
Edit task, filter tasks, priority levels
Learn Git workflows properly
Branches, commits, pull requests, merging
Commit code daily to GitHub
Practice consistent git workflow
